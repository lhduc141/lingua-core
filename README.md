# 🚀 **Overview**

**Linguapanda** is an AI-driven English learning platform designed to deliver a fully personalized learning experience through:

* CEFR-level placement
* AI writing evaluation
* Weekly learning plan generation
* Lesson practice (Reading/Grammar/Vocab/Writing)
* Smart Dictionary + SRS Flashcards

Project is built as the core system for a graduation thesis (2026).
Focus: **AI personalization, EdTech system completeness, end-to-end learning flow.**

---

# ✨ **Core Features**

### 🎯 **1. AI Placement & CEFR Evaluation**

* Vocabulary, Grammar, Reading sections
* Writing submission → AI scoring (GPT-4o/mini)
* CEFR overall + Skill strengths/weaknesses
* Personalized plan based on profile + performance

### 🧠 **2. AI Learning Plan Generator**

* Weekly checklist
* Task types: lessons, writing, SRS review, mini-tests
* Adaptive updates based on progress

### 📘 **3. Practice & Daily Learning Flow**

* Reading, Grammar, Vocabulary lessons
* AI Writing feedback (rubric-based)
* Mini-tests for quick reinforcement
* Learning progress tracking

### 📖 **4. Smart Dictionary + AI Fallback**

* Lookup via dictionary DB
* Missing entries auto-generated by AI
* Examples, IPA, POS, forms
* Auto-create flashcards from dictionary or lesson

### 🔁 **5. SRS Flashcards System**

* Spaced Repetition scheduling
* Ease factor, intervals, due dates
* Daily review UI
* Vocabulary progress dashboard

### 🔐 **6. Authentication & User Management**

* JWT (access + refresh)
* Argon2id password hashing
* Local + Google-ready account system

# 🔄 **Core Learning Flows**

## **Flow 1 – Placement → CEFR Report → Learning Plan**

1. Signup → Profile onboarding
2. Placement test (Vocab, Grammar, Reading, Writing)
3. AI evaluates CEFR
4. AI generates week-by-week learning plan
5. Dashboard shows tasks

## **Flow 2 – Daily Learning & Practice**

* Reading / Grammar / Vocab lessons
* Writing → AI feedback
* Mini-tests
* Task completion update

## **Flow 3 – Smart Dictionary + SRS**

* Dictionary lookup + AI fallback
* Add to flashcards
* Daily SRS review
* Vocabulary progress tracking
